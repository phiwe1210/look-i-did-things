# Progress Log

This folder holds short summaries of work you've done on the project. Claude reads the most recent entries at the start of every session so it has context on what you've been up to without you needing to re-explain.

## How to use it

Drop a new file in here whenever you finish a chunk of work. Naming convention:

```
YYYY-MM-DD-short-slug.md
```

Examples: `2026-05-02-added-radar-chart.md`, `2026-05-03-fixed-week-rollover.md`.

You can put more than one a day — just bump the slug.

## What to put in each file

Keep it cheap to write. The point is to capture *just enough* that future-you (and Claude) can pick up where you left off. Suggested template:

```markdown
# What I did
- bullet
- bullet

# What's next / unfinished
- bullet

# Notes / gotchas
- anything weird, decisions made, links to relevant files
```

If you only have energy for one line, one line is fine. Future-you will still thank you.
